## 17. Live-обновления через REST + TanStack Query + SSE

Цель: сделать так, чтобы посты, комментарии и лайки обновлялись в live-режиме у всех пользователей, которые сейчас находятся в соответствующем треде, без полного перехода на GraphQL и без постоянного polling как основного механизма.

Выбранная схема:

- оставить REST API для команд пользователя: создание поста, создание комментария, создание и удаление лайка;
- использовать SSE для серверных уведомлений о событиях;
- использовать TanStack Query как единый frontend-слой для серверного состояния, кэша, invalidation и фонового обновления;
- оставить polling только как fallback или точечную страховку, если SSE-соединение временно недоступно.
